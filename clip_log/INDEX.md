# ClipMiner — clip log index

Worked examples; rules live in `../skill.md`. **Read this index, not the run files.** Open a run file only when its
clips are relevant (each clip there names its shape and why it was kept or rejected).
Tags: `[universal]` any niche, `[theme]` one profile, `[scorer]` where the API model and GURT disagreed (from each
run's **Scorer vs GURT**), `[workflow]` how GURT runs things. **Counts `(n)`:** add 1 each time a shape or lesson
shows up in a separate clip or run; **3+ = proven**, promote it into `skill.md` and mark it "(in skill.md)".
Run files: Heat = heatmap value(s) the clip overlaps; Loud = seconds ≥ 6 LU over median / max; **Posted:** results
per layout and platform once posted.
